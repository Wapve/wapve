### ✨ What is Wapve?

Wapve is an all-in-one real-time communication ecosystem designed with privacy, aesthetic fluidity, and performance at its core:

- 💬 **Community Servers & Dynamic Channels:** Channel-level granular permissions, custom role hierarchies, and automated AutoMod protection.
- ⚡ **Fluid Messaging:** Real-time Socket.IO synchronization, message scheduling, emoji reactions, poll voting, and high-speed attachments.
- 🎙️ **Private Relay-Only Voice & Video:** Zero-IP-leak WebRTC signaling powered by hardened TURN relays and short-lived HMAC credentials.
- 📱 **Native Multi-Platform:** Responsive web client, native Android mobile app, and security-locked Windows desktop client.
- 🛡️ **Zero-Trust Security:** Passkeys / WebAuthn, 2FA, Argon2id password hashing, and opaque session token architecture.
